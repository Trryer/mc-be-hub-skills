# 模型导入工具与低精度案例

## 输入格式与工具

本能力将 GLB、FBX、OBJ 和 Bedrock geo.json 作为模型重建输入。可使用当前环境中可用的 Blender、Assimp 或项目工具查看/转换文件；先核对目标版本和导出结果中的坐标、层级、材质、贴图与动画。OBJ 通常需同时检查 MTL 和贴图；FBX 需确认 ASCII/二进制及版本。

静态网格/动画定格优先运行内置[通用转换 CLI](automated-pipeline.md)，自动生成距离场、材质 atlas 和 GLSL。格式名称不保证具体变体可读；解析失败时按报告修正或转换，再核对数据。解析 SDF 和完整动作仍按结构适配，不承诺无损自动转换。

## 可复用的低精度案例流程

下列 God Eye 与 Kyushu shader 是性能优先、细节有限的模型近似。这里只提炼它们的典型步骤，不把其细节数量、步数或视觉精度作为新模型的标准。

| 模型来源 | 可复用流程 |
| --- | --- |
| Bedrock cube/bone 模型 | 读取父子层级、pivot、轴向和关键帧；统一坐标后选主要构件与动作，映射到少量 SDF 部件，并扩大动画包围体。 |
| FBX 飞船网格 | 读取实际网格尺寸、轴向、单位和变换；按主要轮廓与重复构件拆件，用固定同源视角先对照灰模，再处理材质。 |

God Eye 展示了层级模型与动画到 SDF 部件的提炼方式；Kyushu 展示了 FBX 尺寸和坐标检查、结构拆分与同机位对照。它们都没有把源网格逐面展开成 GLSL。新模型按用户指定精度和设备预算重新建模。
