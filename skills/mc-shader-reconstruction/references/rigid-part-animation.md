# 分部件距离场与刚体动画

当几何细节适合采样距离场，而动作主要由多个刚体部件运动组成时，按部件烘焙绑定姿态，再播放原始变换。运行时读取距离场及动画轨道，不逐帧遍历源三角形，也不为每个姿态重建整张距离场。

## 判断是否适用

- 核对每个顶点的有效骨骼影响及每个三角形的部件归属。全部顶点只受同一个骨骼驱动的部件，或普通节点刚体动画，可走此路线。
- 混合权重、跨骨骼三角形、形态键、布料和连续弯曲不属于严格刚体动画。先选择可接受的分组近似或其他变形方案，记录误差；不能直接取最大权重后宣称保留完整蒙皮。
- 对整段动作检查变换的正交性和行列式。旋转加平移可直接复用局部距离；缩放、反射和剪切需要单独处理。非均匀缩放不能套用刚体逆变换并保留原距离界。

部件数量、采样率、距离场分辨率和纹理尺寸依据当前源模型、用户精度及设备预算决定。任何一次成功参数都不构成所有复杂动画的默认上限。

## 绑定空间与源轨道

保留源逐面角 UV、法线、材质和三角形索引，将各部件放在同一个归一化绑定模型空间中烘焙。不要单独重新居中每个部件，却仍使用原全局动画矩阵。沿父子链求值源动画；FBX 的 pivot、pre/post rotation、几何变换和绑定矩阵交给可核验的导入器处理。

以列向量为例，若绑定几何点为 `p = N * M * v`，动画点为 `p(t) = N * W_b(t) * G_b * v`，部件作用矩阵为：

```text
T_b(t) = N * W_b(t) * G_b * inverse(M) * inverse(N)
```

`N` 是统一归一化，`M` 是绑定网格实例变换，`W_b(t)` 是求值后的骨骼世界矩阵，`G_b` 是源格式提供的几何到绑定骨骼矩阵。实际导入器命名与空间约定可能不同，先验证静态绑定和关键动作，不按矩阵名称猜顺序。首个动画样本也不一定等于绑定姿态。

## 可复用的轨道编码 CLI

`scripts/model_to_shader/rigid_animation.py` 接收已求值的、均匀采样的刚体矩阵，输出 RGBA8 动画图、GLSL 采样函数与量化误差报告。依赖只有 NumPy、Pillow，已在本技能依赖清单内。它是独立的轨道编码阶段，**不会自动导入整段 FBX 动画、拆件、生成部件距离场或部署游戏资源**；现有 `convert.py` 仍只输出静态/定格姿态。

中间 NPZ 契约：

| 键 | 形状与含义 |
| --- | --- |
| `times` | `[K]`，秒，有限、严格递增、等间隔，K ≥ 2 |
| `transforms` | `[K,B,4,4]`，统一绑定模型空间到当前模型空间的列向量刚体矩阵，B ≥ 1 |

适配器必须先从源曲线求值采样，保留片段时长、停留段及重要关键时刻。不要在带 STEP 的稀疏关键帧上自行线性补帧；需要硬跳变时采用对应播放规则，本工具的相邻样本采用连续插值。快速多圈旋转应检查源曲线和样本间运动，不能只看相同首尾矩阵；相邻角差报告可提示不足，但无法检测整圈采样混叠。

以下最小夹具只演示接口；实际任务替换为源动画求值结果：

```python
import numpy as np
times = np.linspace(0, 1, 31)
transforms = np.broadcast_to(np.eye(4), (31, 2, 4, 4)).copy()
angle = times * np.pi / 2
transforms[:, 1, 0, 0] = transforms[:, 1, 2, 2] = np.cos(angle)
transforms[:, 1, 0, 2] = np.sin(angle)
transforms[:, 1, 2, 0] = -np.sin(angle)
np.savez_compressed('motion.npz', times=times, transforms=transforms)
```

从技能目录运行：

```text
python -B scripts/model_to_shader/rigid_animation.py motion.npz output-motion
```

输出目录必须新建或为空。`--translation-range` 可显式指定对称位移范围，默认覆盖实际位移；不足时报错，不截断动作。`--max-atlas` 和 `--max-mib` 检查动画纹理尺寸及 RGBA8 解码预算，不代表模型全部纹理/运行时的总内存。

编码为每部件四行、每帧八个 16-bit 标量：xyzw 四元数、xyz 平移、一个保留值。每 texel 的 RG、BA 各存一个高低字节对。宽度取覆盖帧数的 2 次幂，尾部补最后一帧；实际帧数、时长、位移范围都来自报告，不写死部件数或采样数。

## Shader 接入

1. 动画图按**线性 RGBA8 数据纹理**绑定，关闭 sRGB 转换和 mipmap，使用 clamp、nearest；保持 PNG 行与采样行一致。先验证首、中、末 texel 的解码，不把字节对交给普通颜色插值。
2. 引入 `animation.glsl`，通过 `msaPose(texture, partIndex, clipSeconds, q, t)` 取姿态。离线统一相邻四元数半球，运行时再次按点积纠正符号，再归一化线性插值；平移按时间线性插值。NLERP 的角速度不等于 SLERP，误差按当前动作检查，需要时提高采样率或替换插值。
3. 对每部件先算一次姿态，再把射线变为局部空间：`localOrigin = rotate(inverse(q), origin-t)`，`localDirection = rotate(inverse(q), direction)`。在该部件自己的绑定包围盒内求交，命中后法线转回模型空间。刚体变换保留射线参数，可直接比较各部件最近命中。
4. 先把根级整体旋转的逆变换作用到射线，再分别逆变换到动画部件；材质采样使用同一命中局部坐标。整体旋转与原动作使用独立速度，冻结其一不能冻结另一项。
5. 全屏和世界位置适配器复用同一几何、材质和动作代码。几何/动画不应在两模式各写一套；接入参数按 [MC 接入流程](mc-integration.md) 核验。

包围体可以采用覆盖全动作的整体边界，或逐部件逆变换后使用绑定姿态紧边界；若有外层裁剪，还须覆盖完整动画轨迹。不能用未扩张的整体绑定 AABB 裁掉运动部件。合并多个距离场 atlas 时，保留部件 offset、tile 尺寸、padding、切片插值与材质图对应关系。

## 片段与验收

循环规则遵循源标记或用户要求。首尾不一致时，不默认拼接，更不自动改成往返播放：先按需求选择单次、停留、正向循环或往返，记录选项；对具有方向语义的动作，倒放可能不成立。编码工具输出首尾旋转/位移差供判断，GLSL 接收已经选好播放规则的片段时间。

按[验收标准](acceptance.md)增加以下动作检查：

- 逐片段检查首、中、尾、关键极值与循环接缝；用源三角网格独立绘制参考，记录每个代表视角的轮廓和材质误差。
- 关闭整体旋转，连续播放源动作，确认部件真的在运动；再冻结动作只旋转整体，最后两者叠加。不能用整体旋转掩盖动作缺失。
- 解码检查全部部件/样本，报告四元数量化角误差、位移误差、最大相邻转角及首尾差。字节编码正确不代表中间姿态视觉已通过，还需比较插值时刻。
- 对实际部署 shader 做目标版本编译、连续预览和游戏验证；用户视觉确认单独记录，未测的设备帧率与专项回归继续保持未测。
