# 代表性模型重建流程

本参考只保留 God Eye 与 Kyushu 两个模型案例中可复用的步骤。已有实现都是性能优先的低精度近似，不是未来模型的精度上限、shader 模板或验收标准。新任务的细节取舍始终服从用户指定的精度和设备预算。

## 通用导入流程

1. 用支持目标文件的导入工具读取 GLB、FBX、OBJ 或 Bedrock geo.json，确认对象、层级、坐标、单位、变换、包围盒、材质和可用动画。
2. 统一源坐标和尺寸，再按部件功能分组。先列主体、关键附属结构、重复构件和影响轮廓的开口。
3. 用少量距离基本体做初始形状，在可重复的模型视角比较轮廓和比例；主结构稳定后再处理局部材质。
4. 只有用户需要动作时才映射动画轨道。挑选主要动作，映射至简化部件，并让包围体覆盖完整动作范围。

## God Eye：Bedrock cube 与骨骼层级

从 geo.json 读取 bone/cube 层级、pivot、坐标轴和主要几何，再从动画数据选出会改变模型辨识度的轨道。将复杂模型拆成炮体、太阳翼等少量 SDF 部件，把主要动画映射到对应部件。示例显示如何从层级模型取形状与动作依据；源模型中的所有 cube 并没有逐个展开为 GLSL 距离计算。

可复用的核心步骤是：先计算父子变换，再统一 pivot 和轴向；识别少数主要结构；先对照静态轮廓，再增加动作；最后扩大包围体覆盖动作轨迹。示例具体轴反射、尺度换算、材质取色和动画时间都只适用于原模型。

## Kyushu：复杂 FBX 网格

读取 FBX 的实际三角形网格、变换和包围盒后，统一单位和朝向。按舰体、舰桥、炮塔、侧舱和尾部等主要轮廓分组，以解析 SDF 和有限重复近似关键结构，并在同一模型视角下与源网格比较。

原例使用一个特定 ASCII FBX 文件和低细节结构近似。它说明先查真实尺寸、坐标和部件，再拆分轮廓的工作方式；不能把案例解析器当成任意 FBX 版本的通用导入器，也不应将案例的细节预算套用到新模型。

## 根据目标精度重建

- 未指定精度：保留最重要的外轮廓和结构，用紧包围体、镜像、有限重复及共享姿态降低成本；交付时说清简化处。
- 指定高精度：增加影响轮廓、开口、局部形状和主要材质的结构，并在游戏中测量成本。
- 指定目标设备或帧率：将其作为预算一并验证。若与指定精度冲突，公开可见的取舍，不静默降精度。

旧 shader 的步数、阴影、AO、颜色数量和尺寸只描述那两个低精度实现，不构成通用参数。
