# 模型数据到解析 SDF

本文用于解析 SDF 与动画的人工适配。静态 GLB/glTF、FBX、OBJ 或动画定格先考虑[可执行管线](automated-pipeline.md)，无需重写通用距离场烘焙与 shader 采样器。

## 输入与导入检查

支持 GLB、FBX、OBJ 和 Bedrock geo.json 作为模型依据。选择实际可用的导入工具，并在开始建模前核实它能读取目标文件版本和需要的数据。导入结果至少要能回答：有哪些对象或部件、坐标轴和单位是什么、父子变换如何应用、包围盒多大、哪些材质与贴图可用、是否存在可用动画。

GLB 可包含节点层级、材质和动画；具体导入器会影响可读取内容。FBX 有 ASCII 与二进制及多个版本，需检查变换、单位和材质链接。OBJ 通常提供静态网格，MTL 和贴图可能是分开的文件。Bedrock geo.json 需读取 geometry、bone、cube、pivot、rotation、parent 和 inflate 等字段。无法可靠读取时，用已安装的 Blender、Assimp 或其他格式工具转换，然后重新核对结果。

转换成中间格式后，可进入自动采样距离场管线或按本文制作解析 SDF；动作适配和用户目标仍须独立核验，不能承诺逐面无损转换。

## 建立统一模型空间

1. 统计对象/骨骼数、三角形或 cube 数、原始包围盒和单位。
2. 先应用节点父变换与模型根变换，再统计最终尺寸。记录源轴到目标轴的映射、中心点和单位比例。
3. 将模型、骨骼枢轴、动作位移、距离函数与包围体统一到同一模型空间。例如将源点平移到模型中心，按统一轴映射，再除以每个 shader 单位对应的源单位数。
4. 用旋转或尺度参考视图核对坐标结果；发现轴向、镜像或比例错误时先修正导入映射，不要在每个部件函数里分别打补丁。

Bedrock cube 的 origin、size 和 inflate 会改变边界；bone 与 cube 的 pivot、rotation 以及父层级会影响姿态。具体轴反射、角度顺序和尺度换算须以源格式与实际模型为准。

## 将模型拆成距离函数

按“主轮廓、次级结构、负空间、表面细节”的次序构造。常见表达包括：

- 舰体、装甲和翼板使用 box、圆角盒、楔形或裁切平面。
- 炮管、支柱和喷口使用有限圆柱、capsule、圆环或组合体。
- 成对结构用局部坐标镜像；非对称结构单独表达。
- 格栅、炮组和肋条使用有限重复，并限制实例范围。
- 影响轮廓或遮挡的开口用差集或独立结构表示；表面接缝、螺栓和发光带可由部件局部坐标生成。

推荐将距离、材质编号和部件函数分开组织。并集用 min，交集用 max，从 A 中减去 B 用 max(dA, -dB)。先让整体模型 AABB 与射线求交，再在有效区间执行距离步进。部件包围体覆盖实际结构，远处可用保守距离下界跳过昂贵计算，近表面则使用真实距离。

刚体平移和旋转应通过逆变换把点转入部件空间。统一缩放需要相应调整距离。非均匀缩放和任意形变会改变距离界，保守低估距离通常只增加迭代成本；高估可能穿过薄结构。命中阈值、最小步长和包围体按模型尺度、最薄构件与目标像素尺寸一起调整。

## 精度按用户要求决定

用户未指定时，性能优先：少量主要构件、紧包围体、镜像与有限重复，克制 raymarch 次数、阴影、AO 和高频材质细节。交付时列出合并、简化或省略的部件。

用户指定高精度时，优先保留比例、辨识轮廓、负空间、重要局部构件和材质差异，按需增加距离函数与求值预算；以部件分组、局部坐标和共享计算控制成本。用户同时给出设备或帧率预算时，说明两项要求的实际取舍，并报告目标设备的测量结果。

高频有机雕刻、透明叠层或大量独立薄片可能不适合少量解析 SDF。可评估网格距离场采样，但需要先验证目标 MC 渲染管线是否支持 3D 纹理；如使用 2D 切片 atlas，还要处理切片间插值、片内过滤和边缘串扰。

## 动画映射

源骨骼或节点是动作依据，简化 SDF 部件才是 shader 运行对象。

1. 选择会显著改变模型辨识度的动作轨道，读取关键帧、父子关系、pivot、单位和插值形式。
2. 记录“源轨道到 SDF 部件、转轴、位移或缩放”的映射。源动画的复杂插值或格式特有表达式不支持时，选择并说明合理的近似方式。
3. 用统一矩阵顺序表达部件变换；对 pivot 旋转，先移到 pivot，再旋转，然后移回。
4. 每个 fragment 在距离步进前计算动画状态，主步进、法线、阴影和 AO 复用同一姿态，避免在每次距离查询中重复计算全部关键帧。
5. 更新全局与分组包围体，使其覆盖动画全范围；局部材质也要跟随部件坐标。

## 网格烘焙距离场

当解析 SDF 难以达到指定形状精度时，可评估以下路线：

    模型导入与清理 → 统一尺度/包围盒 → 采样有符号距离 → 编码距离与属性
    → MC 纹理绑定 → GLSL 采样步进 → 材质和部件动画适配

先用带孔和薄壁的简单网格验证映射与采样误差，再扩大到目标模型。需要明确体素坐标、包围盒 padding、内外符号、距离单位、量化和越界行为。单个距离标量不包含 UV、颜色、金属度或部件层级；这些需要额外数据或程序材质。整体静态距离场也不会自动继承骨骼动画。
