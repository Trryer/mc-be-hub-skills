# 模型转 Shader：默认验收标准

每次模型重建都在实现前记录验收标准，并在交付前按同一份标准复查。用户明确指定的精度、重要部件、动作、贴图和性能预算优先；未指定的项目使用本文默认值。

## 开始时约定

用户尚未给出标准时，提示一次：

> 可补充验收标准，例如必须保留的部件和细节、贴图要求、动画片段、目标设备或帧率；未指定的部分，我会按所选精度的默认标准，对照源模型检查轮廓、贴图和动作，并提供复查证据。

这是可选补充，不是审批步骤；已有明确要求时直接记录，未补充时按默认值继续。确有影响方案的未知项可异步询问，同时继续导入检查。记录标准来源（用户/默认）、精度、必保结构、允许简化项和验证条件。用户未指定精度仍按性能优先；“中精度”不等于强制使用某个固定网格分辨率或步进次数。

## 默认通过条件

| 检查项 | 默认通过条件 |
| --- | --- |
| 输入可信 | 实际读取几何、节点变换、UV、材质及动画轨道；有空 Take 而无有效动作时按静态源记录 |
| 轮廓与结构 | 主体比例、朝向、部件位置、重要负空间正确；用户必保部件齐全；薄片、孔洞、边缘和包围体在代表视角下稳定 |
| 纹理与材质 | 使用用户指定贴图或可核验源材质，保留必要 UV 接缝；没有整体错位、镜像、串色、缺贴图灰模；源图本身的颜色与亮度有对照依据 |
| 动作（如要求） | 每个指定片段及关键部件实际播放；检查首、中、尾和关键极值、循环边界；材质随部件运动，冻结动作后几何稳定 |
| 时间连续性 | 用连续旋转或动作预览检查跳变、漏面、断裂与闪烁；静帧截图通过还须检查时间上的表现 |
| 编译与资源 | 检查实际部署 shader 与目标项目的材质、参数和纹理链；使用真实引擎头文件检查适用 GLSL 版本，有新增错误则修复 |
| 性能 | 在已记录设备、分辨率、构图和参数下测量；满足用户指定预算。未给预算时提供实测成本及精度取舍，不自行承诺固定 FPS |

低精度允许事先记录的小细节合并；关键结构和正确贴图仍需通过。精度降低不能解释关键部件缺失、原本有贴图却变灰、动画未播放等功能错误。纯色、灰模或省略某些动作仅在用户要求或已明确的任务范围内作为预期结果。

## 与源模型对照

1. 源网格参考与部署 shader 使用一致的坐标、比例、姿态和镜头，核对纹理上下方向及透明度约定。至少比较绕主体的 0°、90°、180°、270°；顶部、底部或薄片影响辨识时增加对应视角。主体应有足够屏幕像素判断细节，不能靠缩成很小的画面掩盖误差。
2. 保存并实际打开源模型/重建结果的并排图，逐张检查关键结构与材质，再查看连续旋转或动作预览。渲染成功、图片非空、脚本退出码为 0 都不能代替画面复查。
3. 有可比较的源网格时计算前景轮廓 IoU。材质误差仅在双方共有前景且使用一致贴图、照明、曝光和色彩空间时计算 RGB 平均绝对误差（0～1）；保留测量遮罩与方法。背景占比不参与材质评分。

以下是本技能的默认工程参考线，不是 Minecraft 官方标准，也不替代逐部件复查。每个代表视角都应达到对应参考线，不能只用平均分掩盖某个方向的失败。

| 精度 | 每个视角的轮廓 IoU | 可比条件下的材质 RGB 平均绝对误差 |
| --- | --- | --- |
| 性能优先/低精度（默认） | ≥ 0.85 | ≤ 0.15 |
| 中精度 | ≥ 0.90 | ≤ 0.10 |
| 高精度 | ≥ 0.97 | ≤ 0.06 |

指标条件不成立时标注“不可比较”及原因，改用与用户目标对应的逐部件、逐姿态视觉对照证据；不得编造指标。风格化重建或用户指定更宽/更严标准时，在实现前记录适用标准。发现失败后先修正模型、采样、UV 或测试契约，不通过降低阈值、去掉困难视角、改对照图来制造通过。

## 复查循环与交付

对未通过项记录“预期、实际、证据、修正”。修正后重跑受影响视角、动作和资源检查；几何、贴图、参数或部署 shader 有变化时，旧截图与旧报告不能作为新版本证据。目标仍不满足时明确列出未通过项与原因，不以“编译通过”结束为效果已通过。

在任务交付目录保存对照图、旋转/动作预览和 `report.json`（或等价可复查报告）。报告至少记录：

- 用户要求/默认标准、精度、关键部件、简化范围及每项结论。
- 源模型与贴图、实际部署 shader/关键资源的摘要或版本；镜头、姿态、时间、分辨率、设备和参数。
- 编译、视觉对照、指标、连续播放与性能的实际结果，失败项及未测项。

分别报告“静态/编译检查”“桌面离屏检查”“Minecraft 运行时检查”“用户视觉确认”。通过了哪一层就只宣称哪一层通过；无法运行游戏时完成所有可执行复查，再交付测试命令和明确的游戏内待验项目。最终目标设备的画面与帧率按[游戏内验证](game-validation.md)执行，桌面 GPU 时间不能换算成游戏 FPS。
