# Shader 验收与交付

先记录用户要求的画面、精度、动画、坐标模式及设备预算。没有补充时按所用转换技能的默认标准复查；目标不清但不影响独立工作时先继续检查输入。

修改后核对实际部署的脚本、材质、参数、纹理和生命周期，执行适用编译与资源检查。按请求的模式查看源模型对照及连续动作预览，失败项修正后复测。模型精度标准见[模型验收标准](../../mc-shader-reconstruction/references/acceptance.md)，桌面渲染工具见[离屏技能](../../mc-shader-offscreen-rendering/SKILL.md)。

报告分别列出静态检查、桌面预览、游戏内运行和用户确认的状态；桌面 GPU 计时不能代替游戏帧率。无游戏访问时完成可执行检查，交付复现命令、证据和明确待验项。

如需查询既有具体实现或积累已验证经验，按[私有记录流程](experience-index.md)读取外部资料。任务截图、日志和具体修复记录保存到项目交付目录或私有记录库，不放进公开技能包。
